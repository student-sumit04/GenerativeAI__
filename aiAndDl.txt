#AI Agent 
An AI agent built on a large language model (LLM) is an autonomous software system that uses an LLM as its reasoning core to plan, make decisions, and execute multi-step tasks rather than just generating a single text response.

#chain of thought:
Chain of thought (CoT) is a prompt engineering and AI reasoning technique that guides a large language model (LLM) to solve complex problems through step-by-step intermediate logical reasoning rather than jumping straight to a final answer.


#Reasoning model
A reasoning model (also called a thinking model or large reasoning model) is a Large Language Model fine-tuned to solve multi-step problems by generating hidden or visible intermediate "thinking traces" before giving a final answer. 

eg: deepseek ,chatgpt

Chain of thought , tree of thought, graph of thought

#Small language model:
They have smaller number of parameters ,eg: legal, medical, finance
A small language model (SLM) is a compact artificial intelligence text tool that uses far fewer parameters and less training data than a massive large language model (LLM).

#DIstillation:
LLM distillation is a training method that transfers knowledge from a large, complex model (the "teacher") to a smaller, faster model (the "student") so the smaller model performs similarly while using fewer computing resources

#Quantization:
Quantization in large language models (LLMs) is a compression technique that reduces the memory and computing power needed to run a model by converting its high-precision numbers into lower-precision formats.
