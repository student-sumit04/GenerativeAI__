DOCUMENT LOADERS IN LANGCHAIN
=============================

Purpose
-------
A document loader reads data from a source and converts it into LangChain
Document objects. Each Document contains:

- page_content: the extracted text
- metadata: information such as source, page number, or file name

The loader is the first step in a RAG pipeline:

source -> document loader -> documents -> text splitter -> embeddings -> ChromaDB


PDF LOADER
----------
Use PyPDFLoader for PDF files. It creates one Document per page, which keeps
page numbers available for citations and debugging.

from pathlib import Path
from langchain_community.document_loaders import PyPDFLoader

pdf_path = Path("documents/research-paper.pdf")
loader = PyPDFLoader(str(pdf_path))
documents = loader.load()

print(f"Loaded {len(documents)} pages")
print(documents[0].page_content[:500])
print(documents[0].metadata)


COMMON LOADERS
--------------
PyPDFLoader
	Loads PDF files page by page. Requires pypdf.

TextLoader
	Loads .txt, .md, and other plain-text files.

DirectoryLoader
	Loads multiple files from a directory. It can use a specific loader for
	matching file types.

CSVLoader
	Loads rows from a CSV file. Each row becomes a Document.

WebBaseLoader
	Loads text from web pages. Use it only when web data is part of the RAG
	source collection.


PLAIN TEXT EXAMPLE
------------------
from langchain_community.document_loaders import TextLoader

loader = TextLoader("documents/notes.txt", encoding="utf-8")
documents = loader.load()


LOAD A DIRECTORY OF PDF FILES
-----------------------------
from langchain_community.document_loaders import DirectoryLoader, PyPDFLoader

loader = DirectoryLoader(
	"documents",
	glob="**/*.pdf",
	loader_cls=PyPDFLoader,
	show_progress=True,
)
documents = loader.load()


CHECK LOADED DOCUMENTS
----------------------
Always inspect the result before splitting or embedding it:

for document in documents[:2]:
	print(document.metadata)
	print(document.page_content[:300])

An empty page_content usually means the PDF contains scanned images instead
of selectable text. Such PDFs need OCR before normal text processing.


IMPORTANT PRACTICES
-------------------
- Use paths relative to the project or build paths with pathlib.
- Keep metadata such as source and page number for answer citations.
- Use UTF-8 when loading text files.
- Do not load secrets or .env files as source documents.
- Validate that documents were loaded before passing them to a splitter.
- For large collections, load files in batches and handle bad files clearly.

-------------
